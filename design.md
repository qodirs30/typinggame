# Design System: Ringvitation (The Wedding of Bowo & Maya)

## 1. Visual Theme & Art Direction
- **Vibe & Mood:** Elegant, romantic, structured, and formal. 
- **Style:** A classic wedding invitation layout using structured elementor containers.
- **Key Motif:** Soft, romantic typography with classic script accents, balanced by neutral backgrounds and high-contrast text.

## 2. Color Palette

### Primary & Accent Colors
- **Primary Accent:** `#0170b9` (Used for primary highlights, links, or specific thematic accents)
- **Secondary Accent:** (Typically derived from Elementor globals, largely using neutral/dark grays for this theme)

### Neutral & Background Colors
- **Dark Text / Headings 1:** `#3a3a3a`
- **Dark Text / Headings 2:** `#424242`
- **Body Text:** `#4b4f58`
- **Light Background 1:** `#f5f5f5`
- **Light Background 2:** `#f2f5f7`
- **White (Cards / Containers):** `#ffffff`
- **Black (Deep contrast):** `#000000`

### Semantic Colors
- **Success / Info / Warning:** Relies on default Elementor widget states.

## 3. Typography

### Font Families
- **Sans-serif (Primary & Body):** `Roboto`, `Poppins`
- **Serif (Elegant / Traditional Headers):** `Roboto Slab`, `Cardo`
- **Display / Script (Names & Accents):** `Carattere`
- **Monospace:** `Roboto Mono`

### Font Scale (Estimated based on Elementor global standard)
- **H1 (Hero Names):** Script font (Carattere), large (e.g., `4rem` - `6rem`)
- **H2 (Section Titles):** Serif/Sans-serif, medium-large (e.g., `2rem` - `3rem`)
- **H3 (Subtitles / Dates):** Sans-serif, medium (e.g., `1.5rem` - `2rem`)
- **Body Text:** Sans-serif (Roboto/Poppins), normal (e.g., `1rem`)
- **Small Text (Meta/Captions):** Normal (e.g., `0.875rem`)

### Font Weights
- Base Body: `400`
- Medium/Semibold (Buttons, Subheadings): `500`, `600`
- Bold (Headings): `700`, `800`

## 4. Layout & Spacing

### Container Widths
- **Max Width:** Typical Elementor boxed width (`1140px` or `1200px`)
- **Hero Sections:** `100vw` / `100vh` (Full viewport)

### Spacing Scale (Estimated)
- **Section Padding:** `60px` to `100px` top and bottom
- **Element Gap:** `20px` (Elementor default widget space)
- **Border Radius:** Soft corners on cards (e.g., `8px` to `15px`)

## 5. UI Components

### Buttons
- **Style:** Solid background (using accent color or dark neutral), rounded corners.
- **Typography:** Sans-serif, bold, uppercase or capitalized.

### Cards / Containers
- **Style:** White background (`#ffffff`) on a light gray canvas (`#f5f5f5` / `#f2f5f7`).
- **Shadows:** Soft, diffused box-shadows for elevation.

### Imagery / Media
- **Style:** Hero images with potential overlays to ensure text readability.
- **Borders:** Sometimes framed or rounded depending on the widget.

## 6. Motion & Interaction
- **Hover States:** Slight color darkening on buttons, subtle scale or shadow increase on cards.
- **Scroll:** Smooth scrolling typically enabled.
- **Animations:** Elementor entrance animations (fade in up, zoom in) often applied to sections and widgets as they enter the viewport.
